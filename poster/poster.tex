\begin{panel}{Hypothesis}
A single static vector conflates a word's meanings; WiC asks whether sentence
context separates them (Camacho-Collados \& Pilehvar, 2018; Pilehvar \&
Camacho-Collados, 2019).

\key{Prediction:} frozen BERT target similarity will separate WiC labels better
than either a context-free GloVe target or an average of nearby GloVe words.
\end{panel}

\begin{panel}{Methodology}
\textbf{Data.} Official SuperGLUE v2 WiC: \TrainCount{} balanced training pairs and one
final evaluation on \ValidationCount{} balanced validation pairs. The \TestCount-row
test split has no public labels and is not reported.

\textbf{Static representations.} GloVe 6B \GloveDimensions d (Pennington et al., 2014):
(i) the lemma vector on both sides; (ii) mean in-vocabulary context vectors after
excluding the marked target. Candidate windows were \ContextCandidates{}.

\textbf{Contextual representation.} Unfine-tuned BERT-base-uncased (Devlin et
al., 2019). Fast tokenizer offsets select every WordPiece overlapping the
supplied half-open character span; WordPieces are mean pooled. Candidates:
final layer and mean of the last four layers.

\textbf{Decision rule.} Cosine similarity $\geq$ a global threshold means
same-sense. Thresholds maximize macro F1 on training data only.
\end{panel}

\begin{panel}{Paired evidence, not decorative error bars}
The BERT-minus-context gain is \BertGainCorrect{} additional correct pairs. In
\BootstrapResamples{} paired
bootstrap resamples, the reverse contrast (GloVe minus BERT) remains below zero:
accuracy [\DifferenceLower{}, \DifferenceUpper{}] points and macro F1
[\MacroDifferenceLower{}, \MacroDifferenceUpper{}] points.
\end{panel}

\begin{panel}{The systems fail in opposite directions}
BERT recovers \BertSameRecall{} of same-sense pairs but \BertDifferentRecall{} of
different-sense pairs. GloVe context recovers \ContextSameRecall{} and
\ContextDifferentRecall{}, respectively. These class skews are
thresholded observations, not intrinsic representation preferences.
\end{panel}

\begin{panel}{Limitations}
\begin{itemize}\setlength\itemsep{2mm}
\item One balanced English benchmark and \ValidationCount{} validation pairs.
\item Frozen BERT features, not fine-tuning or a modern encoder comparison.
\item GloVe context is an unweighted lexical mean; syntax is absent.
\item Thresholded cosine tests geometry, not every fact encoded in a vector.
\item \BertErrorCount{} BERT errors remain; selected cases suggest hypotheses,
not causal explanations.
\end{itemize}
\end{panel}

\begin{panel}{Conclusion}
\key{Contextualization matters here.} Under one locked protocol, BERT target
vectors discriminate word meaning substantially better than local static context.
The middle-to-late layer pattern and confident errors also show that ``more
contextual'' is not the same as ``ambiguity solved.''
\end{panel}
